
# Bharath Prime Checker

A lightweight Python package for checking whether an integer is a prime number.

## Installation

```bash
pip install bharath-prime-checker
```

## Usage

```python
from bharath_prime_checker import is_prime

print(is_prime(17))  # True
print(is_prime(20))  # False
```

## Features

- Check whether an integer is prime.
- Simple and lightweight implementation.
- Automated unit tests using pytest.

## Development

Run the tests using:

```bash
python -m pytest -v
```
